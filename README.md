# 短线交易闭环工作台

以「市场情绪周期」为主线的 A 股短线交易工作台，把「盘前定基调 → 盘中看原因 → 盘后照镜子 → 次日带着教训出发」串成一个闭环，回答四个问题：

1. 今天外部环境对 A 股哪些方向有利或不利？
2. 当前市场情绪处在什么阶段，该进攻还是防守？
3. 我的持仓和自选股为什么在异动，值不值得跟？
4. 我在什么样的市场环境下最容易犯错？

仓库内有两个页面，分别运行在同花顺的行情客户端与下单客户端里，共用同一套情绪阶段与归因口径。

## 页面

| 页面 | 运行位置 | 定位 |
| --- | --- | --- |
| `pages/《短线交易闭环作战台》_中0920-6.html` | 同花顺行情客户端 | 完整四模块工作台：盘前外盘映射、短线情绪温度计（含近 20 个交易日走势）、盘中异动归因、盘后交割单复盘与行为诊断 |
| `pages/短线作战台-下单端.html` | 下单客户端「股票 > AI应用」 | 严格真实口径版本：当日情绪全景、盯真实持仓与自选的异动归因、真实账户与交割单复盘 |

两个页面都是单文件 HTML，运行库已在文件中装配，不需要联网加载脚本，也不依赖构建工具。

## 功能与数据范围

### 行情客户端版（四模块）

| 模块 | 关键内容 | 数据范围 |
| --- | --- | --- |
| 盘前映射 | 11 项隔夜外部指标；外盘到 A 股板块的映射（方向、强度、逻辑、代表个股）；首屏取影响最大的 3 条，其余折叠；映射规则可增删改并长期保存；点板块下钻成分股 | 外部指标为最新报价；板块与个股随所选交易日刷新 |
| 情绪温度 | 0–100 综合情绪分仪表盘、六阶段判定与判断依据、8 项核心指标、近 20 个交易日情绪分走势（标出阶段切换、可点选回看）、连板梯队表 | 全市场口径：涨停/跌停/炸板家数、连板高度与梯队、两市成交额 |
| 盘中异动 | 监控持仓与自选股；五类触发条件与可调阈值；每条异动给出时间、幅度、量能与归因类别，并给「跟/观望/回避」参考信号；新异动置顶高亮 | 监控范围来自客户端自选股与自定义板块；板块层面为全市场行业与概念全集 |
| 盘后复盘 | 交割单上传（CSV/TXT）与内置示例；选股/择时/仓位三分解；六类行为偏差（次数、影响金额、典型交易，可点开明细）；各情绪阶段的胜率与盈亏比对照；日报/周报/月报与 3 条改进建议；弱点回写顶部纪律提醒 | 交易笔数不限；情绪阶段对照覆盖最近 20 个交易日，更早的交易标注为区间外且不计入统计 |

页面顶部常驻「今日作战状态栏」：情绪阶段、外盘整体方向、建议仓位区间、来自个人复盘的纪律提醒。四个页签按本地时钟自动打开对应模块，交易日可切换，全页共享同一日期上下文与同一套情绪阶段判定。

### 下单客户端版（三页签）

按「严格真实口径，缺失就隐藏」实现：所有展示项都有真实来源，取不到的部分整块不出现。

| 页签 | 内容 | 来源 |
| --- | --- | --- |
| 情绪全景 | 涨停家数与涨停原因、连板梯队与连板数、炸板家数、跌停家数、上涨/下跌家数、两市成交额、三大指数、行业与概念板块强弱（可下钻成分股） | 客户端数据查询与实时行情 |
| 盘中异动 | 监控范围就是当前登录账户的持仓与自选股；现价、昨收、最高、涨跌幅、量比、换手率、成交额、涨停价与跌停价；归因用资金行为、板块联动、大盘拖累、独立异动四类 | 账户查询、自选股查询、实时行情 |
| 盘后复盘 | 总资产/持仓市值/可用资金/浮动盈亏；每只持仓的成本价、市价、盈亏与盈亏率；按日期区间读历史成交与交割单，结合日线做盈亏归因与行为偏差识别 | 账户查询、历史成交查询、历史日线 |

## 数据口径

- **全部行情、情绪、账户与交割单数据都是真实来源**，不做写死的行情、不用离线快照、失败时不做模拟兜底。
- **唯一的示例数据**：行情客户端版内置一份「示例交割单」，用于没有文件时完整体验复盘功能，界面按钮与来源均明确标注为示例交割单；其成交日期与价格为示例内容，用它复盘时会按示例里的代码去取真实历史行情。
- **本地设置类数据**（不是市场数据）：映射规则、异动阈值、本地补充的监控范围、复盘诊断摘要保存在本机浏览器存储中，用于长期积累。
- **数据不会外传**：页面不含任何 Cookie、口令或账号信息；持仓、资金与交割单都是打开页面时实时读取，不写入任何文件或外部位置。

## 使用方式

### 行情客户端版

在客户端中打开 `pages/《短线交易闭环作战台》_中0920-6.html` 即可。页面依赖客户端提供的数据与行情通道，在普通浏览器中打开只能看到布局与空状态，取不到数据属于预期行为。

### 下单客户端版

需要把页面目录登记给下单客户端的 AI 应用入口（local 模式直接引用目录，不复制文件）。登记时把 `root` 换成你自己的目录，`entry` 指向页面文件：

```json
{
  "id": "duanxian-zhansan",
  "title": "短线作战台",
  "source": {
    "type": "local",
    "root": "<你的仓库目录>\\pages",
    "entry": "短线作战台-下单端.html"
  }
}
```

登记成功后页面出现在「股票 > AI应用」下。页面内的持仓、自选、账户与行情都按打开时的当前登录账户读取，切换账户后刷新即可。

## 已知限制

1. 两页面的取数链路已逐条核对，但页面在客户端内的实际渲染效果需要各自打开确认一次。
2. 行情客户端版的「昨日涨停今日平均涨幅」只在最新交易日可算，因此仅作为核心指标单独展示，不参与综合情绪分。
3. 下单客户端内取不到境外行情、新闻公告与龙虎榜，因此该版本不提供盘前外盘映射，归因不含「个股消息驱动」；情绪也只做当日快照，不做历史走势与环境对照。
4. 交割单按文本表格解析，券商 Excel 导出需另存为 CSV；列名差异过大时可能无法识别，此时只统计条数、不生成盈亏归因。
5. 板块成分股下钻依赖客户端的板块成分缓存，缓存未就绪时该下钻不展开。

## 说明

本项目是交易辅助与复盘工具，只做数据呈现与统计，不预测涨跌，不构成投资建议。回测与统计结论均基于历史数据，实际交易请结合自身仓位与风险承受能力。
